# CityCycle 題目語言統一設計

日期：2026-08-06

## 目標

將 `CityCycle_Functionality_Test_Project_zh-TW.docx` 的題目敘述統一為繁體中文，同時保留所有需要顯示在參賽者程式介面中的指定文字為英文，並在題目文字中使用半形雙引號清楚標示。

## 語言規則

### 使用繁體中文

- 封面說明、目錄、章節名稱及小節名稱。
- 專案背景、一般要求、功能要求、操作步驟及驗證規則。
- 資料與計算規則、測試案例、提交說明及評分標準。
- 線框圖章節名稱、圖說、圖例與「僅供版面參考」說明。
- 表格中的題目說明、評分描述及測試步驟。

### 保留英文並使用半形雙引號

凡是要求實際顯示在程式介面中的文字，於題目敘述中一律以半形雙引號包住，例如：

- 頁面名稱：`"Dashboard"`、`"Station Management"`、`"Rental Console"`、`"Active Rentals"`、`"Smart Assistant"`、`"Rental History"`。
- 按鈕、欄位、篩選器及操作文字：`"Start Rental"`、`"Reset"`、`"Extend"`、`"Return"`。
- 狀態、提示及錯誤訊息：`"Critical"`、`"Low"`、`"Healthy"`、`"OVERTIME"`。
- 任何原題已指定拼字與大小寫的可見字串。

題目章節中的頁面標題採用 `1. "Dashboard" 頁面` 的格式。

### 保留英文但不加雙引號

下列內容屬於技術識別碼而非介面顯示文字，維持英文並使用程式碼字型或等效的技術標示，不加雙引號：

- JSON 檔名，例如 `stations.json`。
- JSON 欄位名稱，例如 `station_id`、`ended_at`。
- 固定資料 ID，例如 `S001`、`M005`、`P_TEST`。
- 公式變數、資料格式、ISO 時間與數值。

## 線框圖處理

- 六張線框圖呈現的是程式介面本身，因此圖內 UI 文字保持英文，不加雙引號。
- 線框圖的 Word 標題、圖說、圖例與參考聲明翻譯為繁體中文。
- 不重畫或改變現有線框圖布局。

## 不變範圍

- 六份 JSON 檔案保持位元組完全不變。
- 功能邏輯、公式、測試資料及預期結果不變。
- 評分項目與總分 15.0 分不變。
- Word 的原有視覺樣式、頁首頁尾與圖片尺寸不變。

## 驗證條件

- 一般英文章節名稱全部完成中文化。
- 題目敘述不保留未標示的介面英文文字。
- 每個指定 UI 字串在題目中均使用成對半形雙引號。
- JSON 檔名、欄位及 ID 不被錯誤翻譯或加上 UI 引號。
- 六張線框圖、替代文字及其章節位置維持完整。
- DOCX 可重新開啟，評分總分仍為 15.0。
- 六份 JSON 的 SHA-256 雜湊保持不變。
