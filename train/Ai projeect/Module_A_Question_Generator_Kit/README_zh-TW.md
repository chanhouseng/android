# Module A Question Generator Kit

本資料夾是一套獨立的新練習工具包，不會修改或接續 CityCycle 舊題。

## 檔案

1. **Device_Snapshot_Module_A_3.5h_zh-TW.md**  
   可直接使用的原創 3.5 小時 Module A 題目，核心為裝置效能參數、圖形化狀態、快照保存與比較，以及系統檔案匯出。

2. **WorldSkills_Module_A_Practice_Scope_and_Question_Generator_zh-TW.md**  
   WSOS 功能地圖、四份參考題的已考／未見功能矩陣、3.5 小時組題公式、題目種子、Markdown 模板及 QA 清單。

3. **AI_Prompt_Generate_WorldSkills_Module_A_zh-TW.md**  
   可直接交給 AI 的主提示詞。使用時同時提供練習範圍 Markdown；AI 會自行選擇未見核心、完成題目與線框圖，並在交付前執行逐項自檢。

## 資源檔

本題不需要圖片、JSON、音訊、影片、帳戶、伺服器或其他外部資源檔。所有驗收資料都來自目標裝置的可取得狀態，以及選手在應用程式內建立的快照。

若比賽環境不能直接改變電量或儲存狀態，仍可利用兩次不同時間的網絡及系統外觀狀態完成主要流程驗收；評分環境亦可使用其原生裝置狀態模擬能力。
