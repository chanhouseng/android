# Booth Handoff — Module A 練習題

本資料夾包含一份 3 小時 30 分鐘、總分 15.0 分的 WorldSkills 風格 Module A 練習題。

## 內容

- `Booth_Handoff_Module_A_3.5h_zh-TW.md`：完整繁體中文題目、ASCII 線框圖、驗收情境、評分配額、介面對照及自檢報告。
- `resources/handoff_valid.bhf`：無重複紀錄的有效匯入檔。
- `resources/handoff_conflicts.bhf`：含一組重複 ID 的有效匯入檔。
- `resources/handoff_invalid.bhf`：同時含狀態錯誤及欄位不足的無效匯入檔。

## 使用方式

1. 將題目 Markdown 提供給選手。
2. 將 `resources` 資料夾中的三個檔案放到評分裝置可由系統選檔介面存取的位置。
3. 依題目第 11 節逐步執行驗收情境，並依第 12 節配分。

所有流程均可離線完成，不需要額外帳戶、網絡服務或特殊硬體。
